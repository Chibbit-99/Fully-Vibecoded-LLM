How does this work?

This is a decoder-only transformer (the GPT architecture) implemented from scratch — no HuggingFace, no PyTorch in the browser. It has – parameters, a byte-level BPE vocabulary of – tokens and a context window of – tokens.

  • tinyllm/tokenizer.py — byte-level BPE trained from scratch, ported line-for-line to web/tokenizer.js.
  • tinyllm/model.py — causal self-attention, pre-LayerNorm blocks, GELU-tanh MLP, weight-tied head.
  • .github/workflows/train.yml — GitHub Actions trains it on CPU, exports model/weights.json.
  • web/engine.js — the same forward pass in JavaScript with an incremental KV cache.
  • tinyllm/server.py — a FastAPI server exposing the identical model over HTTP.

Trained on Tiny Shakespeare (public domain), validation loss – nats/token. The model babbles Shakespeare-flavoured English: it has 4M parameters and no idea what words mean. That is the point of the experiment.
